# 更新日志

每个版本的主要变化。**升级** 一行说明除了面板以外还要不要升级节点 agent；没写的只需升级面板，见 [升级](./guide/upgrade.md)。

完整的提交记录见 [GitHub Releases](https://github.com/kure29/flyx/releases)。

## 3.3.30

2026-10-21

- 节点和监控合在一起：**节点** 列表和卡片直接显示每台节点的 CPU、内存、磁盘、实时网速和本月流量；点节点再点 **监控** 看这台节点的历史曲线和服务监控。管理员菜单里不再有单独的 **监控**，有监控权限的普通用户不变，见 [监控](./guide/forward.md#监控)
- 本月流量按节点上报的网卡计数累计，从这个版本开始统计，按浏览器所在时区从每月 1 号算起
- 隧道的延迟和丢包移到 **中转 → 质量**
- 节点卡片的按钮加上 **监控** 和 **测试点**；还没测出延迟时不再显示“检测”按钮（面板每 3 分钟自动测，重测在延迟结果的菜单里）
- **中转 → 线路** 改版：每条中转一行，只写中转那一段和延迟，不再重复落地名；电脑上线路列在行的右侧
- 修复：节点测试点多、或多条中转从同一节点出发时，部分测试点被节点拒绝（“TCP探测任务过多”）而显示连不上，甚至误发延迟告警。面板现在每台节点同时最多发 8 个探测，多的排队

## 3.3.29

2026-10-21

- 订阅可以看流量统计：订阅详情里切到 **流量统计**，按小时（近 24 小时）、日（近 30 天）、月（近 12 个月）查看下载、上传和折线图；分配了订阅的面板用户在 **我的订阅** 里也能看。从这个版本开始记录，见 [流量统计](./guide/subscription-users.md#流量统计)
- 订阅源可以 **上传订阅文件**：拿不到订阅链接时直接传 Base64、Clash / Mihomo、sing-box 等文件，以后重新上传就能更新；**导入** 里也可以选文件，见 [订阅源](./guide/subscription-sources.md#订阅源)
- 机场做前置更方便：订阅源可以设 **用途**（普通 / 中转 / 落地）；链式代理能按 **整个订阅源** 设中转或落地，机场改名、增删节点自动跟上，还能按名称筛选（如只用香港、IEPL 节点）、把没用上的节点去掉、让中转节点不混进节点选择；新建订阅会按用途自动设好，见 [链式代理](./guide/subscription-rules.md#链式代理)
- 选择规则生成的模板，分类改用真实图标；导出的 Mihomo / Stash（`icon`）和 Surge（`icon-url`）策略组带图标，可以从 Qure 等图标库挑选或填图片地址，也能添加自己的图标订阅
- 入站 **出站** 里选默认去向时，节点多也能返回：顶部加了返回按钮，搜索框固定在上方
- 导入节点和订阅源的“仅中转”开关改叫 **只通过我的转发访问**，避免和链式代理里的“中转”混淆

## 3.3.28

2026-10-21

- 双栈节点的回程 IPv4、IPv6 两条都测：回程详情里每个测试点分两行，卡片上 IPv6 线路不一样时多一个“v6”小标签，IPv6 线路变化也会提醒，见 [回程线路](./guide/latency.md#回程线路)
- 菜单按 **线路 / 分发 / 系统** 分组，笔记本屏幕上不再把“共享”“设置”挤出去；**用户** 页合并了用户、分组和限速三个标签，用户行显示流量进度条
- 内核移到 **节点 → 内核**，**落地** 只放入站和订阅源
- 入站的 **分流** 改名 **出站**（出站 IP 策略、默认去向和分流规则都在这里）
- 监控页节点列表改为 CPU / 内存进度条和网速、流量、TCP / UDP 连接数分栏显示
- 修复：在线演示里回程标签都是灰色
- **升级**：双栈回程需要把节点 agent 升级到 3.3.28 及以上

## 3.3.27

2026-10-20

- 只有 IPv6 的节点也能看回程：节点没有 IPv4、或测试点只有 IPv6 地址时自动改用 IPv6 检测，按每一跳的归属网络识别 CN2 / 163 / 9929 / 4837 / CMI，结果旁标 **IPv6**；测不了时直接说明原因，见 [回程线路](./guide/latency.md#回程线路)
- 隧道的入口是 nftables 节点时，表单不再显示转发引擎，改为提示由 nftables 转发；引擎选项写明各自适合的场景
- 入站可以设置出站 IP 策略：自动、仅 IPv4、仅 IPv6、优先 IPv4、优先 IPv6（连不上时回退另一种），入站监听不受影响；在入站的高级选项或分流里设置，优先模式需要 Xray 25.6.8+ 或 sing-box 1.12+，见 [出站 IP 策略](./guide/routing.md#出站-ip-策略)
- 订阅模板新增 **选择规则**：不用写配置，勾选分类、添加自定义规则和策略组就能生成 Mihomo / sing-box / Surge 模板，保存后可以继续编辑；生成的 Mihomo 模板 Stash、Shadowrocket 也能用，见 [订阅模板](./guide/subscription-templates.md)
- 订阅的线路筛选新增 **有中转优先显示中转**：落地有启用的中转时只显示中转，没有中转时保留直连，见 [对接中转](./guide/relay.md)
- 修复：手机上下拉框选中后仍多出一项“请选择”
- 修复：没有 systemd-resolved 的服务器上，sing-box 1.13+ 可能解析不了域名，导致 REALITY / ShadowTLS 握手和出站失败
- 感谢 @jiuaiya 贡献出站 IP 策略、模板规则编辑器、中转优先和 DNS 修复
- **升级**：IPv6 回程需要把节点 agent 升级到 3.3.27 及以上

## 3.3.26

2026-10-20

- 中转支持 realm 转发引擎：端口转发隧道在编辑时可以把 **转发引擎** 选为 realm，入口节点会自动安装 realm 来跑这条隧道的转发，占用更低；TCP / UDP、多目标负载、Proxy Protocol 和流量统计照常可用，不支持限速和连接数限制，见 [realm 引擎](./guide/forward.md#realm-引擎)
- 已有隧道可以随时切换引擎，面板会把转发规则迁移过去
- **升级**：realm 引擎需要把节点 agent 升级到 3.3.26 及以上
