# 更新日志

每个版本的主要变化。**升级** 一行说明除了面板以外还要不要升级节点 agent；没写的只需升级面板，见 [升级](./guide/upgrade.md)。

完整的提交记录见 [GitHub Releases](https://github.com/kure29/flyx/releases)。

## 3.3.22

2026-10-20

- Snell 内核可以安装 Surge 官方的 snell-server **6.0.0（测试版）**，支持 v6 入站和流量整形（默认 / unshaped）；默认版本仍是 5.0.1
- 注意：官方 6.0.0 **只接受 v6 客户端**，v4 / v5 客户端连不上；面板会拦住版本对不上的入站和内核版本切换，详见 [Snell 用哪个内核](./guide/kernels.md#snell-用哪个内核)
- 官方 6.0.0 没有 armv7 版本，armv7 节点安装时会提示架构不支持

## 3.3.21

2026-10-20

- 中转线路的端到端延迟：**中转 → 线路** 里每条线路显示经它到各测试点的估算延迟（前置到测试点 + 前置 → IX → 落地每一段），点开看每一段多少毫秒、哪段不通，见 [对接中转 - 延迟](./guide/relay.md#延迟)
- sing-box 1.14 及以上的客户端（SFA / SFI / SFM）订阅里也有 Snell 节点；旧客户端照旧不带
- Snell 节点可以被 sing-box 1.14 及以上内核的入站选作链式出站或分流去向
- Snell v6 可选流量整形（默认 / unshaped），客户端订阅和 Surge 配置自动带上
- Release 页面开头列出本版的更新内容，文档新增 [更新日志](./changelog.md)
- 修复：延迟测试点超过 10 个时保存失败（现在最多 30 个）；sing-box 上的 Snell v5 入站不再误显示监听 UDP

## 3.3.20

2026-10-20

- sing-box 内核支持内置 Snell（需要 sing-box 1.14 及以上）：v4 / v5 / v6 客户端、Snell + ShadowTLS 不用再装 shadow-tls，还能分流和链式出站。和 Snell 内核的区别见 [Snell 用哪个内核](./guide/kernels.md#snell-用哪个内核)
- 用了 1.14 功能（内置 Snell、自动申请证书）的 sing-box 不能再换回 1.14 以前的版本
- 文档重新整理：目录分成开始 / 落地 / 中转与转发 / 订阅 / 运维，新增基本概念、内核与协议、延迟与回程、备份与恢复等页面
