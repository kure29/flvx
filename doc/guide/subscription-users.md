# 凭据、到期与流量

订阅可以分给别人用：每个订阅有自己的凭据，可以设到期日期和流量上限，到期或用完自动断开。

## 独立凭据

- 每个订阅有自己的 UUID / 密码，和你的凭据同时写进节点配置，互不影响
- 可以设到期日期（到期当天 23:59 后断开）和流量上限，留空就是不限
- **停用**、**删除** 或 **到期** 后，面板会把它的凭据从节点上删掉，已导入的配置也连不上了
- **重置链接和凭据**：旧链接和对方已导入的配置立即失效，适合链接泄露时使用
- 支持单独凭据的协议：VLESS、VMess、Trojan、Hysteria2、TUIC、AnyTLS、NaïveProxy、SOCKS5、HTTP。Shadowsocks、Snell、WireGuard 和导入的节点只能共用原来的密码：停用后订阅失效，但对方已经导入的配置仍能连接（界面上会标出“共用凭据”）
- 3 天内到期会推送 [通知](./notify.md)

## 流量上限

- 每个订阅单独统计流量（上传 + 下载），可以设 **流量上限**，用完自动断开，和到期一样
- **每月重置**：选每月几号，到那天 0 点自动清零；也可以在订阅详情里点 **重置流量** 手动清零，超限断开的会立即恢复
- 用到 90% 和用完时会推送 [通知](./notify.md)，概览页的“需要处理”里也会列出
- 客户端里能看到已用流量、总量和到期时间（`Subscription-Userinfo`）
- 统计在落地节点上进行：每个订阅走自己的出站，节点用 nftables 计数，Xray 和 sing-box 都支持。需要节点上有 nftables，并且节点 agent 要和面板一起更新到最新版（旧 agent 能正常转发，只是不计数）
- 只统计支持单独凭据的协议。共用凭据的落地（Shadowsocks、Snell、导入的节点）分不清是谁在用，不计入
