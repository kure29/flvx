# 订阅

**订阅** 页管理所有订阅链接。思路和 Sub-Store 一样：**来源 → 处理 → 输出**。每个订阅选一批落地，按需过滤、改名，客户端拿到的格式按 UA 自动识别（也可以复制指定格式的链接）。

升级前的订阅链接会变成这里的“我的订阅”，链接不变；原来的订阅设置和共享用户也会自动迁移过来。

## 订阅与凭据

所有订阅在同一个列表里，靠名称区分（例如“我的手机”“小明”）。

- 新建的订阅都有自己的 UUID / 密码，和你的凭据同时写进节点配置，互不影响
- 可以设到期日期（到期当天 23:59 后断开）和流量上限，留空就是不限；停用、到期或流量用完后，面板会把它的凭据从节点上删掉

编辑订阅分成 **基本 / 节点 / 命名 / 规则 / 链式代理 / 预览** 六页，在任一页都能直接保存：

- **基本**：名称、到期、流量上限、每月重置、备注
- **节点**：来源、筛选和 [JS 脚本](#js-脚本)
- **命名**：改名、国旗、前缀、排序
- **规则**：分流规则、按地区分组
- **链式代理**：勾选落地和中转节点
- **预览**：打开就自动生成，看最终的节点和链式角色

订阅列表右上角可以在列表和卡片之间切换，选择会记在浏览器里。

## 导入到客户端

点订阅打开详情，按客户端选择：**点客户端直接唤起 App 导入**，右侧按钮复制该格式的链接。也可以复制上面的通用链接，客户端按 UA 自动拿到对应格式。

| 客户端 | 格式 | 一键导入 | 链式代理 | 分流规则 |
|--------|------|----------|----------|----------|
| Clash（Clash Verge、Mihomo Party、FlClash 等） | Clash / Mihomo 配置 | `clash://` | ✓ | ✓（需 mihomo 内核） |
| sing-box（SFA / SFI / SFM） | sing-box 配置 | `sing-box://` | ✓ | ✓（需 1.12 及以上） |
| Shadowrocket | Clash 节点列表 | `shadowrocket://` | ✓（每个中转各生成一个“落地（经 中转）”节点） | ✓（下发完整配置） |
| Loon | Loon 节点 | `loon://` | ✗ | ✓（下发完整配置，复制链接导入） |
| Quantumult X | QX 节点 | `quantumult-x://` | ✗ | ✓（下发完整配置，复制链接导入） |
| Surge | Surge 配置 | `surge://` | ✓ | ✓ |
| Stash | Clash 配置 | `stash://` | ✓ | ✗ |
| 通用 | Base64 分享链接（v2rayN、NekoBox 等） | 仅复制 | ✗ | ✗ |

- 客户端不支持的协议会自动略过，例如 Loon 没有 TUIC，Quantumult X 没有 Hysteria2 / TUIC，Surge 没有 VLESS；VLESS Encryption 只在 Clash / Mihomo 和通用订阅里，WireGuard 只在 Clash / Mihomo、sing-box 和通用订阅里
- Loon 和 Quantumult X 的节点格式没有前置代理参数，订阅里的落地节点是直连
- 指定格式的链接：在订阅链接后加 `?format=clash`（或 `singbox`、`shadowrocket`、`loon`、`qx`、`surge`、`stash`、`base64`）

## 来源

- **全部落地**：包括以后新增的落地，不用再回来勾选
- **指定落地**：只勾选需要的，分“自建”“导入”和“订阅源”三组。订阅源按整个源勾选，以后更新进来的节点会自动跟上；只要其中一部分可以用下面的过滤

落地的中转线路会跟着它一起出现在订阅里。

## 订阅源

在 **落地 → 订阅源** 添加机场或别人的订阅链接，相当于 Sub-Store 的远程订阅。也可以在 **落地 → 导入** 里粘贴订阅地址，打开 **定时同步**（默认打开）就会存成订阅源；关掉则只导入一次：

- 添加后立即拉取一次，节点出现在 **落地** 页“订阅源 · 名称”分组里，可以和其他导入节点一样检测、接中转、放进订阅
- **自动更新**：手动 / 6 小时 / 12 小时 / 每天。也可以点卡片右边的按钮立即更新
- 更新时按 **名称** 对上已有节点（名称变了再按地址对）：地址变了就跟着改，挂在上面的中转也会改到新地址；订阅里没有了就删除，但挂着中转的会保留，免得中转断掉
- 拉取失败或返回空内容时保留现有节点，卡片上显示错误
- 机场返回的流量和到期信息（`Subscription-Userinfo`）会显示在卡片上
- **新节点设为仅中转**：新加进来的节点只用来接中转，不直接进订阅
- 删除订阅源时可以选连同节点一起删除，或只删订阅源、节点留下变成普通的导入节点

典型用法：订阅选“指定落地”，勾上自己的落地和机场订阅源，再在“节点”页筛选地区、“命名”页加国旗和排序，一个链接全搞定。

## 筛选和命名

“节点”页的 **筛选** 决定要哪些节点，“命名”页决定节点叫什么、怎么排。生成时按固定顺序执行：**筛选 → 改名 → 国旗 → 前缀 → 去重 → 排序 → 脚本**。

| 设置 | 说明 |
|------|------|
| 线路 | 全部 / 只要中转 / 只要直连 |
| 地区 | 只保留选中的地区；“其他”是名称里认不出地区的节点 |
| 协议 | 只保留选中的协议 |
| 名称包含 / 排除 | 多个关键词用 `\|` 分隔（不区分大小写），或用 `/正则/` |
| 改名规则 | 每行一条 `要替换的 => 替换成`，右边留空就是删除，`/.../` 是正则 |
| 自动加国旗 | 按名称识别地区，在前面加国旗；已经有国旗的不重复加 |
| 名称前缀 | 给所有节点加同一个前缀 |
| 去重 | 地址、端口、协议都相同的只保留第一个 |
| 排序 | 面板顺序，或按名称（`02` 排在 `10` 前面） |
| 按地区分组 | 在“规则”页：Clash / sing-box / Surge 里每个地区一个自动测速组，列在“节点选择”最前面；开启分流规则时自动包含 |

例如导入的节点叫 `花云|香港🇭🇰|1.0x|01`，改名规则：

```
花云| =>
/\|[0-9.]+x/ =>
| => -
```

会变成 `香港🇭🇰-01`。编辑时点 **看看结果** 可以先预览，会显示每个节点改名前后的名字和过滤掉了几个。

### JS 脚本

上面的设置不够用时，在“节点”页的 **JS 脚本** 里写一个 `operator` 函数，一次处理整个节点列表（写法同 Sub-Store 的脚本操作）：

```js
function operator(nodes) {
  return nodes
    .filter(n => !/过期|剩余/.test(n.name))
    .map(n => {
      n.name = n.name.replace("IEPL", "专线")
      return n
    })
    .sort((a, b) => a.name.localeCompare(b.name))
}
```

返回的数组决定留下哪些节点、什么顺序；没返回的节点会被去掉。每个节点有这些字段：

| 字段 | 说明 |
|------|------|
| `name` | 当前名称（已经过改名、国旗、前缀），**唯一能改的字段** |
| `original` | 原名 |
| `server` / `port` | 地址和端口 |
| `protocol` | 协议，如 `vless`、`shadowsocks`、`hysteria2` |
| `region` | 识别出的地区，如 `🇭🇰 香港`，认不出是空的 |
| `line` | `relay`（中转）或 `direct`（直连） |

- 脚本在上面所有步骤之后运行，只能用标准 JavaScript，不能联网、读文件或用定时器
- 运行超过 1 秒会被停止；脚本出错时按没有脚本生成，预览页顶部会显示错误
- 点 **试运行并预览** 可以马上看结果；`console.log` 可以写但不会输出

## 链式代理

让客户端先连 **中转节点**，再经它连 **落地节点**，网站看到的是落地节点的 IP。适合“国内 → 香港中转 → 美国落地”这类线路，或者给机场节点套一层自己的落地。

在编辑订阅的 **链式代理** 页，列表里是这个订阅的所有节点，每个节点点 **不用 / 落地 / 中转**：

- **落地节点**：挂上中转组，即 Clash / Mihomo 的 `dialer-proxy`、sing-box 的 `detour`、Surge 的 `underlying-proxy`
- **中转节点**：放进“中转节点”组

生成的订阅里多两个分组：

| 分组 | 说明 |
|------|------|
| 落地节点 | 选出口，排在“节点选择”的第一个 |
| 中转节点 | 选中转，所有落地节点都经这里选中的节点连接 |

```yaml
proxies:
  - name: "美国 落地 01"
    type: vless
    # ...
    dialer-proxy: "中转节点"
```

- 落地和中转都至少选一个才生效；页面顶部会显示“已开启”
- 记的是节点原名，之后改名、加国旗不影响；节点被删掉或改了原名需要重新勾选
- 旧版本用名称表达式设置的链式代理照常生效，页面上会提示；在列表里重新勾选后改用勾选结果
- 预览里会标出“落地”“中转”
- 落地节点仍可在“节点选择”和地区分组里直接选，选中后同样经中转连接；中转节点也可以单独使用
- 通用分享链接（Base64）无法表达链式，落地节点在里面是直连
- 延迟叠加，速度取决于最慢的一段；落地是 Hysteria2 / TUIC 等 UDP 协议时，中转节点要能转发 UDP

> 这是客户端侧的链式。想让服务器自己把流量转到另一个节点出去（客户端无感），用入站的 [分流](./nodes.md#分流)。

## 分流规则

默认生成的配置只有“局域网直连、其余走节点选择”两条规则。在订阅的 **分流规则** 里打开后，Clash（mihomo）、sing-box、Surge、Shadowrocket、Loon 和 Quantumult X 的配置会带上：

- **基础规则**：局域网和国内域名 / IP 走“全球直连”，境外网站走“节点选择”，剩下的走“漏网之鱼”
- **勾选的分组**：每组是一个可单独选节点的策略组

| 分组 | 默认 | 包含 |
|------|------|------|
| 广告拦截 | 拦截 | 常见广告域名（sing-box 里直接拦截，没有可切换的组） |
| AI 服务 | 美国地区组 | OpenAI、Claude、Gemini 及其他境外 AI |
| YouTube | 节点选择 | YouTube |
| Netflix | 节点选择 | Netflix |
| 国外媒体 | 节点选择 | Disney+、Spotify、TikTok |
| Telegram | 节点选择 | Telegram |
| Google | 节点选择 | Google |
| 微软服务 | 直连 | 微软、OneDrive（GitHub 仍走节点选择） |
| 苹果服务 | 直连 | Apple |
| 游戏平台 | 直连 | Steam 等游戏平台（国内 CDN 始终直连） |

- 打开后自动按地区分组，每个分组都能直接选地区；没有美国节点时，AI 服务默认走节点选择
- Clash 和 sing-box 还会带上 DNS：国内域名用阿里 / 腾讯 DoH 解析，其余经节点用 Google / Cloudflare DoH 解析，避免 DNS 泄漏；Clash 另开启 fake-ip 和域名嗅探
- 规则集是 GitHub 上的远程文件，客户端定期自动更新：Clash 用 [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat) 的 `.mrs`，sing-box 用同一仓库的 `.srs`，Surge、Shadowrocket、Loon、Quantumult X 用 [blackmatrix7/ios_rule_script](https://github.com/blackmatrix7/ios_rule_script) 里对应客户端的规则
- Clash 和 sing-box 经“节点选择”下载规则集，在国内也能下载；其余客户端自己下载规则集，网络连不上 GitHub 时规则会暂时缺失
- **Shadowrocket、Loon、Quantumult X 的节点订阅无法携带规则和策略组**，所以开启后这三个客户端的链接改为下发 **完整配置**（节点直接写在配置里），导入会替换 App 里原来的配置，原来作为节点订阅导入的需要重新导入：
  - Shadowrocket：Clash 格式的配置，点客户端直接导入（`shadowrocket://config/add/`）
  - Loon / Quantumult X：复制链接，在 App 的配置管理里“从 URL 下载”
  - 链式代理：Shadowrocket 照旧生成“落地（经 中转）”节点；Loon 和 Quantumult X 没有前置代理参数，落地节点仍是直连
- `.mrs` 只有 mihomo 内核能读，Stash 订阅不带分流规则；已停更的 Clash Premium / Clash for Windows 原版内核不支持

## 独立凭据

- 每个订阅有自己的 UUID / 密码，和你的凭据同时写进节点配置，互不影响
- **停用**、**删除** 或 **到期** 后，面板会把它的凭据从节点上删掉，已导入的配置也连不上了
- **重置链接和凭据**：旧链接和对方已导入的配置立即失效，适合链接泄露时使用
- 支持单独凭据的协议：VLESS、VMess、Trojan、Hysteria2、TUIC、AnyTLS、NaïveProxy、SOCKS5、HTTP。Shadowsocks、Snell、WireGuard 和导入的节点只能共用原来的密码：停用后订阅失效，但对方已经导入的配置仍能连接（界面上会标出“共用凭据”）
- 3 天内到期会推送 [通知](./notify.md)

### 流量上限

- 每个订阅单独统计流量（上传 + 下载），可以设 **流量上限**，用完自动断开，和到期一样
- **每月重置**：选每月几号，到那天 0 点自动清零；也可以在订阅详情里点 **重置流量** 手动清零，超限断开的会立即恢复
- 用到 90% 和用完时会推送 [通知](./notify.md)，概览页的“需要处理”里也会列出
- 客户端里能看到已用流量、总量和到期时间（`Subscription-Userinfo`）
- 统计在落地节点上进行：每个订阅走自己的出站，节点用 nftables 计数，Xray 和 sing-box 都支持。需要节点上有 nftables，并且节点 agent 要和面板一起更新到最新版（旧 agent 能正常转发，只是不计数）
- 只统计支持单独凭据的协议。共用凭据的落地（Shadowsocks、Snell、导入的节点）分不清是谁在用，不计入

## 其他

- 所有订阅都包含在 **网站配置 → 数据备份与恢复** 的“内核与入站”里
