# 公开状态页

一个不用登录就能看的只读页面，像探针一样展示节点的实时状态，可以把链接发给朋友或贴在群里。

## 开启

在 **设置 → 公开状态页** 里：

- 打开 **开启公开状态页**，可以改标题（默认“节点状态”），点 **保存**
- 勾选 **显示的节点**，勾选立即生效；没勾选的节点不会出现在页面上；也可以直接用节点列表每行的 **公开** 开关
- 保存后下面会显示链接，点 **复制** 发出去，地址形如 `https://面板地址/status/3f9c1a7e2b4d6e80`

页面上有：

- 顶部汇总：在线节点、实时带宽、本月流量、连接数
- 按地区筛选（按节点名自动识别，如“香港”“HK”）
- 每个节点的 CPU、内存、磁盘、实时网速、本月流量，到各延迟测试点的延迟和回程线路（只有线路名，比如 CN2 GIA，不显示路由每一跳），离线的节点变灰
- 每个测试点最近约一小时（20 轮）的延迟和丢包，用一排小方块表示：绿色正常，黄色偏慢或有丢包，红色很慢或不通
- 电脑上右上角可以切换列表和卡片，手机上固定是卡片

本月流量从节点上报的网卡计数累加，从更新到这个版本后开始统计，按查看者的时区从每月 1 号算起。

登录面板的普通用户如果有 **监控** 权限，在 **监控** 里看到的是同样的只读视图（所有节点，不显示 IP），没有顶部汇总。

## 安全

公开状态页不会给后台多开一道门：

- 页面只调用一个只读接口，只返回上面列出的字段；**IP、端口、密钥、备注和 agent 版本都不会返回**
- 只返回勾选的节点；状态页关闭或链接不对时接口返回 404，看起来就像不存在
- 链接里的路径是随机生成的，猜不到；只有管理员能看到它。链接泄露了可以点 **换新链接**，旧链接立即失效
- 接口结果在服务端缓存几秒，并按 IP 限制访问频率，刷新再快也拖不垮面板
- 页面上没有登录入口，也不会跳到后台；所有管理接口照旧要登录

### 用单独的域名（可选）

想让公开状态页和后台完全分开，可以给状态页一个单独的域名：这个域名只放行状态页的接口，其他接口（登录、管理、节点连接）一律返回 404，后台用另一个不公开的域名访问。以面板前端跑在 `127.0.0.1:6366`（安装脚本的默认前端端口）为例：

Caddy：

```
status.example.com {
    @status path /api/v1/open_api/status/*
    @blocked path /api/* /system-info* /flow/*
    handle @status {
        reverse_proxy 127.0.0.1:6366
    }
    handle @blocked {
        respond 404
    }
    handle {
        reverse_proxy 127.0.0.1:6366
    }
}
```

Nginx：

```nginx
server {
    server_name status.example.com;
    location /api/v1/open_api/status/ {
        proxy_pass http://127.0.0.1:6366;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
    location ~ ^/(api|system-info|flow)/ {
        return 404;
    }
    location / {
        proxy_pass http://127.0.0.1:6366;
        proxy_set_header Host $host;
    }
}
```

在这个域名上即使打开了登录页也登录不了，后台接口都到不了面板。
