在一个面板里管理中转与落地，一键部署 Xray / sing-box / Snell 节点并对接中转

GitHub

多内核节点

Xray、sing-box、Snell v4 / v5 按节点安装，VLESS Reality、Hysteria2、TUIC、AnyTLS、NaïveProxy、ShadowTLS 等模板一键创建。

一键对接中转

端口转发、隧道转发，或经 IX 的多跳线路；中转线路自动进入订阅，可开启入站白名单和真实客户端 IP。

导入节点

粘贴分享链接、Clash / sing-box / Surge 配置或订阅地址，别处搭好的节点也能对接中转、加入订阅。

订阅

参考 Sub-Store：多个订阅各自选落地、过滤、改名、按地区分组，可分享给他人；按客户端自动返回 Clash / Mihomo、sing-box、Surge 或 base64。

流量转发

TCP / UDP 端口转发与隧道转发，配额、限速、单向或双向计费。

面板内升级

网站配置里检查更新、一键升级，也可以用安装脚本更新。
